Educational tool, not financial advice. SMC/ICT concepts (order blocks, fair value gaps, liquidity sweeps, BOS/CHoCH) and the Elliott Wave count are pattern-recognition heuristics applied here mechanically to historical candles — they are not a proven predictive edge, and institutional intent is inferred, not observed. Wave counting in particular is inherently subjective in real Elliott Wave practice (alternate counts are normal); the count shown here is one simplified, rules-checked reading of the last six swing points, not an authoritative label. Markers can repaint as new candles close. Crypto data comes from Binance's public feed and streams tick-by-tick over WebSocket when Live is on. Forex and index data comes from Twelve Data using your own free API key, refreshed by polling roughly every 20 seconds — free-tier Twelve Data quotes are typically delayed 1–15 minutes, not true real-time, and index/forex symbol coverage varies by their data provider. Always backtest and manage risk independently of any signal shown here. Once a BUY/SELL fires, it stays locked (SL and TP1 don't move) until price actually touches one of them; the next call only appears after that resolution, and the trade log is a simple simulated record of those SL/TP1 touches on this page — it isn't a real position, executed order, or verified track record. The optional AI signal sends the already-computed structure summary (not raw candles) to Anthropic's API using your own API key entered above, and asks a language model to weigh it into a single read; it is a second opinion generated from the same mechanical detections shown elsewhere on this page, not an independent market analysis, and it can be wrong, inconsistent between runs, or unavailable if the key is missing or rate-limited. Each click is a billed API call against your own key.
